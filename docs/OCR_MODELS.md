# Bundled OCR language data

The Windows package bundles Tesseract language models for English, Spanish,
French, Dutch, Simplified Chinese, and orientation detection. OCR runs locally;
book pages are not uploaded by the OCR pipeline.

The Dutch `nld.traineddata` file was retrieved from the official
`tesseract-ocr/tessdata_fast` repository on 2026-09-28.

- SHA-256: `CED0E5E046A84C908A6AA7ACCBEF9A232C4A5D9A8276691B81C6EE64D02963F6`
- Upstream: <https://github.com/tesseract-ocr/tessdata_fast>

The Tesseract executable and trained data retain their upstream licenses. See
`THIRD_PARTY_NOTICES.md` before redistributing a build.
