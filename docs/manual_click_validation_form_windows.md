# Windows frozen EXE manual click-validation form

Use this form only with the disposable folder generated by `tools/prepare_manual_release_validation.py`. Do not select a personal library and do not use personal documents.

No manual outcomes are recorded for this public build. Earlier approvals are
not carried into this snapshot; fill out the form only after testing this build.

## Prepare the disposable workspace

From the repository root, run:

```powershell
python tools/prepare_manual_release_validation.py
```

If `python` is not available in `PATH`, use the Python interpreter used to build the EXE:

```powershell
& "C:\Users\<user>\AppData\Local\Programs\Python\Python312\python.exe" tools\prepare_manual_release_validation.py
```

The helper creates:

```text
manual_release_validation/
  appdata/
  localappdata/
  input/
    add_books/
    exact_duplicate/
    metadata_search/
  library/
  review/
  ocr/
  expected/
  results/
  launch_frozen_validation.ps1
```

Start the frozen EXE with isolated application data:

```powershell
powershell -ExecutionPolicy Bypass -File ".\manual_release_validation\launch_frozen_validation.ps1"
```

## Generate the local filesystem report

Close the EXE first. Then run:

```powershell
python tools/check_manual_release_results.py
```

If `python` is not available in `PATH`, use the same explicit interpreter path used for preparation.

The checker writes:

```text
manual_release_validation/results/manual_release_results.md
```

It verifies filesystem evidence only. It does not claim that Tkinter buttons were clicked and it does not delete anything.

## Cleanup after review

Keep the temporary workspace until you have read the generated report. Then close the EXE and remove only the marked validation folder:

```powershell
$target = (Resolve-Path ".\manual_release_validation").Path
$repo = (Resolve-Path ".").Path
if ($target.StartsWith($repo, [System.StringComparison]::OrdinalIgnoreCase)) {
    Remove-Item -LiteralPath $target -Recurse -Force
} else {
    throw "Refusing to remove a folder outside the repository."
}
```
