# Manage Your Library 0.4.1 for Windows

Version 0.4.1 refines the 0.4 workspace into a warm editorial library inspired by a quiet personal reading room.

## Visual design

- Warm ivory surfaces, terracotta actions, subtle separators, and an earth-toned dark theme.
- Editorial serif typography for the library identity, book titles, authors, and selected-book details.
- Rounded search field, filter pills, navigation selection, buttons, cards, and inspector.
- Responsive cover gallery with more breathing room and a larger selected-book preview.
- Compact sidebar collection summary and reduced dashboard clutter.
- Quick format filters, recent/title ordering, and clear cover/table controls.

## Existing behavior preserved

The guided import, duplicate review, operation journal, Undo, local cover extraction, local `Tesseract` OCR, `pypdfium2` rendering, optional metadata lookup, and offline mode remain available. OCR remains local, the app does not upload documents, and duplicate quarantine remains recoverable in `.trash_manageyourlibrary/`.

The Windows build continues to use hash-locked dependencies. See [windows_0.4.1_checksums.md](windows_0.4.1_checksums.md) for the validated artifact.
